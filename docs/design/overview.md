# 中心となる考え方

> **人間はコードではなく、契約と証拠を信頼する。実装は外に出られない箱に閉じ込め、確かめるのは信頼基盤に任せる。**

| 信頼の根拠 | 保証すること | 担い手 |
|---|---|---|
| 契約 | 何を受け取り、何を返し、何をしてよいか | 人間が承認する |
| 封じ込め | 宣言した以上のことはできない | 信頼基盤が強制する |
| 証拠 | 契約に適合することを、この実行物で確かめた | 信頼基盤が発行する |

Saird は、2つの部分でできている。

- **記述形式**:契約と組立書を書くための形式
- **ツール群**:契約と組立書を検査し、実行するもの

実装は任意の言語で書き、Wasm にコンパイルする。

Saird は実装の正しさを証明しない。保証するのは、実装を信頼しなくても使える範囲である。

用語は [用語集](../reference/glossary.md) を参照。
