# 粒度

- 箱は入れ子にできる。
- 人間は承認境界を決める。初期状態では、一番外側の箱の契約だけを表示する。
- 外側の契約を承認するときは、**権限サマリ**も表示する。権限サマリは、内側のすべての箱が組立書で受け取る権限を、箱ごとに一覧にしたものである。
- 箱を「開く」と、子箱の契約と組立書が見える。実装は、どの深さでも見えない。
- 境界の内側にある子箱は、親の承認に含まれる。
- 子箱に渡す権限は、親の権限に含まれなければならない([包含の規則](../reference/permissions.md#包含の規則))。
- 書き込み・外部送信・秘密情報・金銭を扱う箱は、権限サマリで強調して表示する。
