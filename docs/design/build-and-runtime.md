# ビルド時と実行時

| 区分 | 決めること | 決める人 |
|---|---|---|
| ビルド時 | 契約、組立書、依存部品の版(ハッシュで固定)、実装、テストとレシート | AIが作り、人間が契約を承認する |
| 実行時 | メモリ上限、CPU上限(Wasm の燃料=実行した命令数の上限)、タイムアウト、同時実行数、権限への実物の割り当て、秘密情報、ログの出し先 | 運用者 |

- 実行時の設定は、権限を狭められるが、広げられない。
- 権限の割り当て先を変えた場合は、記録して通知する。
- 本番の資源上限が、テスト時の観測プロファイルの最大値より小さい場合は警告する。
- 資源エラーの再現性は、燃料で判定する。
