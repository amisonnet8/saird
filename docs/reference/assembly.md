# 組立書と呼び出し

## 組立書

- 組立書は契約には含めない。ただし、組立書の権限は権限サマリとして外側の承認時に表示する([粒度](../design/granularity.md))。
- 各箱には、必要な権限だけを渡す。
- 依存部品はハッシュで固定する。部品が変わったら、依存する箱の適合証明を取り直す。

書き方は [文法](syntax.md)、例は [Checkout](../examples/checkout.md)。

## 呼び出し

- 呼び出しの形は、相手がどこにあっても同じである(所在透過)。
- 障害の種類は隠さない。
- 土台には Wasm Component Model を使う。値はコピーして渡す。

例は [呼び出し](../examples/call.md)。
