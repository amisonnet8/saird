# effects

effects は、ホストが保証する副作用の性質である。テストでは確かめない。

## atomic

- 1回の呼び出しを、kv の1つのトランザクションにする。
- 成功時に確定し、`error` と `fault` のときは取り消す。
- kv のトランザクションは、直列化可能(同時に実行しても、順に実行したのと同じ結果)とする。
- `atomic` を宣言できるのは、書き込み先が kv だけの箱である。http などの外部への書き込み権限を持つ箱には宣言できない(検査器が拒否する)。

## idempotent by K for T

| 項目 | 規則 |
|---|---|
| 前提 | `atomic` と同時に宣言する |
| 記録 | ホストが (K, 入力ハッシュ, 結果) を、kv の書き込みと同じトランザクションで記録する |
| 記録の置き場所 | ホストの内部領域に置く。箱の kv 範囲には含まれない。箱からは読み書きできず、`kv_before` / `kv_after` にも現れない |
| 入力ハッシュ | 入力全体を正規化してからハッシュを取る。正規化の規則は、WIT 型に従った正規形でのシリアライズ(フィールドは宣言順、文字列は NFC、数値は正規表記、リストは順序を保つ)とする |
| 同じ K・同じ入力 | 入力ハッシュが一致すれば、記録した結果を返す。箱は実行しない |
| 同じ K・違う入力 | `IdempotencyConflict` を返す |
| 記録する結果 | `ok` と `error` |
| `fault` のとき | 記録しない。kv は取り消されているので、再実行してよい |
| 保持期間 | 契約に T を書く。T を過ぎた K は、新しい呼び出しとして扱う。同じ K・同じ入力でも箱を再実行し、副作用も再び適用する(例:`ReserveStock` に24時間後に同じ注文を送ると、在庫は再び引き当てられる) |
| 同時に同じ K | 直列化され、後の呼び出しは記録した結果を受け取る |

## effects を宣言しない箱

- 外部への書き込みを含む箱、または複数の資源に書き込む箱は、effects を宣言しない。
- このような箱の `fault` は「変更が残っている可能性がある」ものとして扱い、画面にもそう表示する。
- 補償(途中まで進んだ処理の取り消し)は、その箱を呼ぶ親の箱が担う。親の箱は、補償の結果を自分の `ensures` と `errors` に書く。Saird は自動では補償しない。
