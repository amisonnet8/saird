# 用語集

| 用語 | 意味 |
|---|---|
| 箱(box) | 唯一の単位。契約・実装・証拠をひとまとめにしたもの |
| 契約(contract) | 人間が読む部分。入力・出力・権限・テストの4欄 |
| 実装(body) | AIが書く中身。人間には見せない。WebAssembly(Wasm)にコンパイルする |
| 組立書(assembly) | 箱のつなぎ方と、各箱に渡す権限 |
| 封印物(sealed artifact) | ビルドの結果。内容のハッシュ(指紋のような固有値)で識別する |
| レシート(receipt) | 信頼基盤が出す、署名付きの実行記録 |
| 観測プロファイル | レシートに記録する、権限の使用・資源・結果の分布 |
| 契約承認 | 人間が契約に付ける署名 |
| 適合証明 | 信頼基盤が「この封印物は承認済みの契約に適合する」と付ける署名 |
| 信頼基盤(trusted base) | 人間が信頼する道具一式([信頼基盤](../design/trust.md#信頼基盤))。AIは変更できない |
| 承認境界 | 人間が「ここまで見る」と決めた深さ |
| 標準箱 | kv・http・clock など、外の世界に触れる部品。信頼基盤の一部 |
