# 権限

## kv

- キーは文字列ではなく、セグメントの列として扱う。範囲はテンプレートで書く(例:`"inventory/{sku}"`)。
- テンプレートの変数は、1つのセグメントだけに一致する。`/` や空文字列は含められない。セグメントは Unicode 正規化(NFC)したうえで、完全一致で比べる。
- 操作は `read`(1つのキーを取得する)、`write`(1つのキーを設定・削除する)、両方を許す `read-write` のどれかとする。範囲内のキーを列挙するには、`scan` を別に宣言する。
- `kv[x]` は、テンプレートの変数に x を当てはめたキーを表す。

## http

- 範囲は「メソッド+ホスト(完全一致)+パステンプレート+許可するクエリ名」で書く。例:`POST "pay.example.com/charge"`。
- リダイレクトは追わない。3xx の応答は、そのまま箱に返す。
- 名前解決したアドレスが、プライベートアドレスやループバックアドレスであれば、接続を拒否する。

## 包含の規則

- 範囲が等しいか、テンプレートの変数がより強く制約されている場合に、範囲を含むとみなす。
- 操作については、read ⊂ read-write とする。

## 秘密情報

- 秘密情報は、宛先(http の範囲)と、付与するヘッダー名に紐付ける。ホストが送信時に付与し、箱には値を渡さない。
- 箱に返す応答から、ホストが秘密情報の値(そのままの形と base64 の形)を伏せ字にする。
- ログとレシートには、秘密情報を付与したヘッダーを記録しない。
- 署名や暗号化には、鍵の値ではなく鍵の識別子を渡す。処理は暗号用の標準箱が行う。
